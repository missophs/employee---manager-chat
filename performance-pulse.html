How to use this

  1. The manager sets this up — fills in both names below and shares the app. The Employee / Manager switch at the top shows each side; with the cloud version, your login decides your side automatically.
  2. Before your 1:1, go to My 1:1 and add topics. Stuck for words? Use the suggested questions — or write your own.
  3. The other person gets a ping that something was added — never the content itself.
  4. In the meeting, work through the agenda together, mark each topic (Discussed, Needs Assistance…), and capture actions.
  5. Everything saves as you go. Moving between tabs never loses anything, and you can go back and change any item at any time.
  6. Want HR to have something? Use Send to HR on the Export tab — it creates the file and opens an email to your HR contact. HR is not notified automatically — they receive it, and know about it, when you choose to send it.

Block Kit layouts

Pick a ping. The JSON is valid Block Kit built from what is actually in this workspace right now — paste it into Slack’s Block Kit Builder and it renders as a real message.


        
Block Kit describes how a Slack message looks. It is not what delivers it. Sending these for real needs a Slack app with a server behind it, which also means performance data would live on that server rather than on this device. SLACK.md in this repo lays out exactly what that path costs and what it changes.
